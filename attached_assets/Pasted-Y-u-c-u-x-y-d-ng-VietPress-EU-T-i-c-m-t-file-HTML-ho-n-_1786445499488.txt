Yêu cầu xây dựng VietPress EU

Tôi đã có một file HTML hoàn chỉnh cho giao diện trang chủ VietPress EU.

Hãy sử dụng giao diện hiện tại làm thiết kế gốc. KHÔNG thiết kế lại website từ đầu và không thay đổi phong cách tổng thể nếu không cần thiết.

Mục tiêu là biến website HTML tĩnh này thành một cổng thông tin điện tử hoàn chỉnh, dễ quản trị bởi người không biết lập trình.

14. AI News Assistant

Trong Admin tạo chức năng:

"Nhập bài từ URL"

Editor nhập URL một bài báo.

Hệ thống chuẩn bị dữ liệu cho workflow AI để có thể:

Đọc nội dung nguồn.
Tạo bản nháp tiếng Việt.
Đề xuất title.
Tạo summary.
Phân loại category.
Xác định country.
Đề xuất tags.
Tạo SEO description.

QUAN TRỌNG:

AI KHÔNG được tự động publish.

Kết quả luôn phải lưu dưới:

status = draft

Editor phải kiểm tra rồi mới Publish.

Nếu việc đọc URL hoặc gọi AI cần API/service bên ngoài, hãy xây giao diện và abstraction/service layer trước, rồi chỉ rõ API key hoặc service nào cần kết nối. Không hard-code API key.

17. Exchange rate

"Bảng tỷ giá" trên header phải dẫn tới trang:

/ty-gia

Chuẩn bị khả năng lấy tỷ giá CZK/EUR/USD/VND từ API phù hợp.

Nếu API chưa được cấu hình, dùng fallback và không để website crash.

19. Migration nội dung hiện tại

Hãy chuyển các bài mẫu hiện tại thành seed data trong database để sau khi migration homepage vẫn giống gần với thiết kế hiện tại.

20. Nguyên tắc triển khai

Thực hiện theo từng giai đoạn.

PHASE 1:
Phân tích source HTML hiện tại.

PHASE 2:
Refactor thành application structure.

PHASE 3:
Database + seed data.

PHASE 4:
Dynamic homepage.

PHASE 5:
Article/category/country/search pages.

PHASE 6:
Admin CMS.

PHASE 7:
Events/newsletter/ads.

PHASE 8:
AI News Assistant.

PHASE 9:
SEO + optimization.

Sau mỗi phase:

chạy application
kiểm tra lỗi
sửa lỗi
không phá vỡ giao diện đã hoạt động

Không thay đổi toàn bộ architecture giữa chừng nếu không thực sự cần thiết.

Trước tiên hãy:

Phân tích project hiện tại.
Đề xuất architecture đơn giản nhất.
Lập kế hoạch migration.
Sau đó bắt đầu triển khai Phase 1–3.
